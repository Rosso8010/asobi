あそびのくに — 音源について
==============================
audio/ フォルダ内の音源はご家庭で用意したファイルです。
ボタン名 = ファイル名(拡張子なし)として再生されます。
曲を増やすときは mp3 を audio/ に入れて、audio/playlist.json に
ファイル名(拡張子なし)を追記してください。

背景・UIアートについて
======================
home-world.webp / mode-math.webp / mode-motion.webp /
mode-learning.webp / mode-creative.webp は、このアプリ専用に
OpenAI の画像生成機能で制作したオリジナル背景です。
home-mode-icons-v1.png は、トップ画面の14モードを同じ画風で
見分けられるように制作したオリジナルのアイコンセットです。
koro-toy-parts-v1.png は、コロコロコースのボール・坂・ファン・
ワープ・ゴールなどを「おもちゃ工房」の画風で統一するために
制作したオリジナルの部品セットです。
rush-world.webp / rush-success.png / rush-paper.png / rush-bin.png /
rush-animals.webp / rush-objects-a.webp / rush-objects-b.webp /
rush-props.webp も、ミニゲームラッシュ専用に制作した
オリジナル素材です。表示時に絵が切れないよう、rush-art/ 内へ
1点ずつ余白付きで切り出した素材をアプリでは使用しています。
rush-world-candy.webp / rush-world-space.webp と、rush-art/ 内の
key / chest / drum / bell / crown / wand は、ラッシュの追加世界と
成功演出用に OpenAI の画像生成機能で制作したオリジナル素材です。
piano-stage-art.webp / kanji-studio-art.webp は、ピアノステージと
かんじ練習画面のために OpenAI の画像生成機能で制作した
オリジナル背景です。

文字の書き順データについて
==========================
かんじ・ひらがな・カタカナモードの画線・筆順データには
KanjiVG を使用しています。アプリ内へパスデータを埋め込み、
オフラインでも動作する形にしています。

ピアノ課題曲について
==================
「エリーゼのために」「トルコ行進曲」などのガイドは、
パブリックドメインの楽譜を参照し、2オクターブで子どもが
遊びやすい長さ・音域へ編曲しています。
Mutopia Project: https://www.ibiblio.org/mutopia/
IMSLP: https://imslp.org/

ピアノ音色について
================
ピアノステージの音色には、Alexander Holm 氏が収録した
Salamander Grand Piano（Yamaha C5）のサンプルを使用しています。
アプリでは2オクターブ向けに必要な音だけをMP3で同梱し、
オフラインで再生できるようにしています。
Author: Alexander Holm
License: Creative Commons Attribution 3.0 (CC BY 3.0)
https://sfzinstruments.github.io/pianos/salamander/
https://creativecommons.org/licenses/by/3.0/

日本地図パズルについて
======================
出典：地球地図日本（国土地理院）／Data of Japan
https://github.com/dataofjapan/land
元の japan.topojson を投影・簡略化して使用。沖縄の位置を別枠へ移動し、小島を省略しています。
配布元の記載：非営利利用は出典元の明記。営利利用は出典元の明記と著作権者への利用報告。
変換プログラム：build-map.py。元データ：japan-source.topojson。

数ブロックの顔・装飾・色分け・体形は、ユーザーが提示した参考画像をもとにCanvasで描画しています。参考画像の写真ファイルは同梱していません。
