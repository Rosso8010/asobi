# もふもふ大合戦（MOFUMOFU WARS）v4

小さな仲間を出撃させ、戦線の押し引き・編成・砲台のタイミングで敵城を攻略する完全オリジナルのレーン戦略ゲームです。見た目は親しみやすく、収集・育成・タイム攻略は大人も詰められる設計です。

## 内容

- 6章×10面、計60面。各章の10面目は固有ボス戦。
- 仲間36種。うち17種は冒険加入、19種はガチャ加入。
- 敵24種。各章の部隊に新しい敵を追加。
- 6つの生成戦場背景：草原、森、氷湖、黄昏要塞、歯車の空都、月夜のサンゴ海。
- 仲間の役割は🛡️まもり／⚡しんげき／🎯えんご／💥そうじ／👑きりふだの5種。
- 8種の固有能力：装甲／鈍足／資金増加／停止／本気／回復／3枚盾／会心。
- 編成画面に新しい生成キャラクターアートを追加。
- 編成により城HP、初期資金、砲台充填、資金速度のチームボーナスが発動。
- レベル1〜20、Lv10＋🥚で進化。基地強化3種。
- 出撃前に敵の種類、距離、敵城HP、報酬を確認可能。
- ステージごとに3勲章：突破／目標タイム／城HP70%以上。
- オフラインキャッシュ対応。

## 💾 セーブあんしん

- A/B二重スロットへ連番・チェックサム付きで交互保存。片方が壊れても新しい正常スロットを選ぶ。
- 通常セーブとは別に「ひとつ前」「その日の最初」「復旧前」「形式移行前」を端末内へ保存。
- `saveSchema`をアプリ版から分離し、`0→1→2...`と順番に変換できる移行基盤を実装。
- 仲間ID・ステージIDを将来変更する場合の旧ID→新ID変換表を用意。
- 新しい形式のセーブを古いアプリで開いた場合は書き込みを停止し、元データを保護。
- ホームの「セーブあんしん」から、チェックサム付き `MWB1` セーブコードを発行。
- 旧 `MW4` セーブコードも引き続き読み込み可能。
- コードはコピーまたは共有でき、別端末・別ブラウザでも貼り付けて復旧可能。
- 読み込み前の記録も救出用スロットへ退避。欠損・改変されたコードは拒否する。

端末内バックアップはSafariのサイトデータ削除には耐えません。長期保存にはセーブコードをメモ、メール、ファイルなど端末外へ保存してください。

## 🧠 ひらめき作戦

戦闘中に任意で1問だけ挑戦できます。問題画面の間は戦闘が停止します。

- 1章：10までのたし算
- 2章：足りない数
- 3章：かけ算
- 4章：わり算
- 5章：数の規則性
- 6章：混合計算
- 全章：漢字の読みがランダムで出題

間違えても敗北・減点にはならず、何度でも再挑戦できます。正解すると以下が発動します。

- 所持資金＋30%
- 12秒間、資金速度1.45倍
- 砲台を即時充填
- 5問正解ごとにガチャチケット1枚

## ガチャ

確率は仲間追加時もゲーム内で自動計算して表示します。ガチャ限定仲間がなければクリア不能、という設計にはしていません。

- 初回は未所持確定。
- ★が4回続いたら次は★★以上。
- ★★★が19回出なければ次は★★★。
- 重複が7回続いたら、未所持がいる場合は次で確定。
- 重複はLv10まで直接レベルアップ。以降はレア度別の強化素材へ変換。
- 再戦4勝ごとにチケット1枚。再戦報酬を抽選にはしない。

## 「あそびのくに」との連携

同一GitHub Pages配下の隠しモードとして起動できます。ホームの「🎪 あそびのくに 🎪」を約2.8秒長押しします。

計算、文字練習、コロコロ、ひらめきアドベンチャーの記録は `asobi-mofu-link-v1` を介してチケットへ変換されます。端末やドメインが異なる場合、ブラウザ保存領域は共有されません。

## バランス検証

`balance-test.cjs` による自動出撃結果：

- 冒険加入17体からの編成、Lv20＋進化＋基地最大：60/60面クリア。
- 基本加入5体、Lv10＋基地Lv6相当：第3章まで30/30面クリア。
- 追加章向け編成、Lv15＋進化＋基地Lv8相当：第5・6章20/20面クリア。
- 最終面6-10：ガチャ限定なしで突破可能。

これは運による進行不能を防ぐ下限確認です。実プレイでは編成、出す順番、砲台、ひらめき作戦の使用時機で結果が変わります。
